💸 Expense Tracker (Java Core + JUnit 5 + Maven)
Консольное приложение для учёта расходов с модульным тестированием
🛠 Стек: Java 17, Stream API, Collections, JUnit 5, Maven, Git
✅ Реализовал(а):  

    Ввод/валидацию данных, сохранение в CSV с обработкой ошибок  
    Аналитику через Stream API: фильтрация, группировка, статистика  
    Юнит-тесты на ключевые методы (покрытие: toCsv(), toString())  
    Сборку проекта через Maven с поддержкой Java 17
javac *.java
cd ..
java -cp src Main
