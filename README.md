# 💸 Expense Tracker (Java Core)

Консольное приложение для учёта личных расходов с аналитикой и сохранением данных.

## 🚀 Функционал
- ➕ Добавление расходов с валидацией ввода
- 💾 Автосохранение/загрузка из CSV
- 🔍 Фильтрация по категории
- 📊 Статистика: сумма, среднее, мин/макс чек
- 🏆 Топ-3 категорий по расходам
- ⚡ Устойчивость к повреждённым данным ( graceful degradation )

## 🛠 Стек
- Java 17+
- Stream API, `java.time`, `java.io`
- ООП, коллекции, обработка исключений

```bash
cd src
javac *.java
cd ..
